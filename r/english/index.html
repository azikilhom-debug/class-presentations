# Basic event rules:
pA <- 0.40
pB <- 0.30
pA_and_B <- 0.10
pA_or_B <- pA + pB - pA_and_B
7 / 10STUDENTS PASS
0.70ESTIMATED P(PASS)
0.30P(FAIL)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)    |    P(Aᶜ) = 1 − P(A)
WHY mean(TRUE/FALSE) WORKSFor a logical vector, R treats TRUE as 1 and FALSE as 0 when calculating the mean. This gives the sample proportion.
