CASE 1 · FRAUD ALERTThink in 10,000 transactions

A “90% sensitive” alert can still be wrong most of the time

Fraud prevalence: 1%
Sensitivity: 90%
False-positive rate: 12%
Before calculating, estimate: is the posterior closer to 7%, 50%, or 90%?
True alerts = 100 × .90 = 90
False alerts = 9,900 × .12 = 1,188

P(Fraud | Alert)
= 90 / (90 + 1,188)
= 7.04%
THE CORE IDEA

Posterior today = prior tomorrow

prior → evidence 1 → posterior 1 → evidence 2 → posterior 2

Sequential updating is repeated Bayes. But multiplying evidence is valid only when the signals are conditionally independent given the underlying state.

CASE 1 CONTINUED · A SECOND ALERT

Two independent signals change the decision

ODDS FORM OF BAYES
Prior odds = .01/.99
LR+ = .90/.12 = 7.5
Posterior odds after 2 alerts
= (.01/.99) × 7.5²
= 0.5682
Convert odds to probability:
0.5682 / 1.5682
36.2%
Still uncertain—but very different from 7.04%.
WARNING · DOUBLE-COUNTING

Two alerts are not always two pieces of evidence

Reasonably independent

An automated transaction model and a later identity-document verification.

Likely dependent

Two risk models trained on the same customer history and the same variables.

FROM BELIEF TO ACTION

When is a probability high enough?

Potential fraud loss: 10 million UZS
Investigation cost: 0.5 million UZS
Investigate when expected avoided loss exceeds investigation cost.
p × 10m > 0.5m
p > 0.5 / 10

Decision threshold = 5%

Both the first alert (7.04%) and the second (36.2%) justify investigation under these assumptions.

THE NEXT LANGUAGE

An event says what happened. A random variable says how much.

A random variable is a rule that assigns a numerical value to every outcome in the sample space.

X : outcome → number
EXAMPLE · ONE LOAN

The same outcome can support different variables

Default indicator D
Repaid → 0
Late → 0
Defaulted → 1
Bank profit X, million UZS
Repaid → +1.2
Late → +0.4
Defaulted → −8.0
PROBABILITY MASS FUNCTION

List every value and its probability

OutcomexP(X=x)
Repaid1.20.80
Late0.40.15
Defaulted−8.00.05
VALID PMF CHECK

Every p ≥ 0
Σp = 1

Then calculate:
E[X] = Σ x·P(X=x)
EXPECTED VALUE
E[X] = 1.2(.80) + 0.4(.15) − 8(.05)
= 0.62m UZS

Interpretation: across many comparable loans, average profit approaches 620,000 UZS per loan. It is not the profit from any single loan.

R LAB · 20 MINUTESSave as week03b.R

Update probabilities, then simulate profit

# Bayes after one alert
prior <- 0.01; sensitivity <- 0.90; fpr <- 0.12
posterior <- sensitivity*prior /
  (sensitivity*prior + fpr*(1-prior))
posterior

# One-loan profit model
profit <- c(1.2, 0.4, -8)
prob   <- c(0.80, 0.15, 0.05)
sum(profit * prob)

set.seed(20260910)
x <- sample(profit, 10000, replace=TRUE, prob=prob)
mean(x); sd(x); hist(x, col="#ec3013")
