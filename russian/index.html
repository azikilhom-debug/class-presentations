Самостоятельная работа · 7 часов на тему

Три одинаковых вида работы по каждой из десяти оцениваемых тем плюс 20 часов подготовки к экзаменам. Всего 90 часов.

AИзучить теорию по теме
BВыполнить практические задачи
CПродвинуть собственный проект по данным

Проект по данным выполняется весь семестр: один исследовательский вопрос, один набор данных и один письменный вывод. Итог — презентация или краткий визуальный отчёт.
