ТИПЫ ДАННЫХПЕРВЫЙ ШАГ

Четыре типа переменных

Номинальные

Категории без порядка: факультет, город, пол.

Порядковые

Есть порядок: низкий / средний / высокий.

Дискретные

Счётные числа: число студентов, заявок, ошибок.

Непрерывные

Измерения: доход, рост, время, цена.

СРЕДНЕЕФОРМУЛА

Арифметическое среднее

x̄ = (x₁ + x₂ + … + xₙ) / n

Как считать

Складываем все значения и делим на количество наблюдений.

Зачем

Среднее показывает «точку баланса» данных. Оно удобно для дальнейших расчётов.

СРЕДНЕЕ НА ПРИМЕРЕШАГ ЗА ШАГОМ

Расчёт для 12 кафе

429 / 12 = 35,75

Вывод

Средняя дневная выручка кафе равна 35,75 млн сум.

Но есть проблема

Одно кафе с 96 млн сум сильно тянет среднее вверх.

МЕДИАНАУСТОЙЧИВЫЙ ЦЕНТР

Медиана — значение посередине

Сначала упорядочиваем данные. Если наблюдений чётное число, берём среднее двух центральных значений.

Me = (31 + 33) / 2 = 32

Медиана лучше описывает «типичное» значение, когда есть выбросы.

МОДАКАТЕГОРИИ И ЧАСТОТЫ

Мода — самое частое значение

Когда полезна

Для категорий: самый популярный факультет, самый частый ответ в анкете.

Когда слабая

Для непрерывных денежных данных точные повторения часто отсутствуют.

РАЗМАХ, ДИСПЕРСИЯ, СТАНДАРТНОЕ ОТКЛОНЕНИЕТРИ УРОВНЯ

Как измерить разброс

Размах

max − min. Быстро, но зависит от крайних значений.

Дисперсия

Средний квадрат отклонений от среднего.

Стандартное отклонение

Корень из дисперсии. Возвращает единицы измерения.

СТАНДАРТНОЕ ОТКЛОНЕНИЕФОРМУЛА

Почему именно квадрат?

s = √[ Σ(xᵢ − x̄)² / (n − 1) ]

Квадрат

Убирает минусы и сильнее наказывает большие отклонения.

Корень

Возвращает показатель в исходные единицы: млн сум, минуты, баллы.

КОЭФФИЦИЕНТ ВАРИАЦИИСРАВНЕНИЕ РИСКА

Когда единицы разные

CV = s / x̄ × 100%

CV показывает разброс относительно среднего. Это удобно, когда сравниваем разные масштабы: маленький магазин и большой филиал.

КВАРТИЛИПЯТЬ ЧИСЕЛ

Five-number summary

min, Q₁, Me, Q₃, max

Квартили делят упорядоченные данные на четыре части. На следующем занятии из них строится box plot.
