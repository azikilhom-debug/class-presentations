ПРОБЛЕМАПОЧЕМУ НУЖНА КОМБИНАТОРИКА

Иногда исходов слишком много

Если нужно выбрать 5 студентов из 40, перечислять все варианты вручную бессмысленно. Нужны правила счёта.

ПРАВИЛО УМНОЖЕНИЯПОСЛЕДОВАТЕЛЬНЫЕ ВЫБОРЫ

Если шаги независимы по количеству вариантов

m вариантов × n вариантов = m·n вариантов

Пример: 4 факультета и 3 языка обучения дают 4×3=12 комбинаций.

ПЕРЕСТАНОВКИПОРЯДОК ВАЖЕН

Когда место имеет значение

P(n,r) = n! / (n−r)!

Используем, когда выбираем r объектов из n и порядок выбранных объектов важен.

СОЧЕТАНИЯПОРЯДОК НЕ ВАЖЕН

Когда важен только состав группы

C(n,r) = n! / [r!(n−r)!]

Команда в R: choose(n, r).

КАК ВЫБРАТЬ ФОРМУЛУШПАРГАЛКА

Задайте один вопрос

Порядок важен?

Да → перестановки.

Порядок не важен?

Нет → сочетания.

«Президент, вице-президент, секретарь» — порядок важен. «Команда из 3 человек» — порядок не важен.

РЕДКИЕ СОБЫТИЯПОВТОРЕНИЯ

Редкое перестаёт быть редким при многих попытках

P(хотя бы один успех)=1−(1−p)ⁿ

Даже если p мало, при большом n вероятность хотя бы одного события может быть высокой.

МИНИ-ГОЛОСОВАНИЕБЫСТРО

Верно или нет?

Если шанс ошибки в одной операции 1%, то в 100 операциях ошибка почти невозможна?

Нет. P(хотя бы одна ошибка)=1−0,99¹⁰⁰≈63,4%.

СИМУЛЯЦИЯИДЕЯ

Вероятность через много повторений

set.seed(1)
rolls <- sample(1:6, size = 10000, replace = TRUE)
mean(rolls == 6)

Чем больше повторений, тем ближе результат к теоретической вероятности.

ГРАФИКИ В BASE RБЫСТРЫЙ СТАРТ

Первые команды

hist(rolls)
barplot(table(rolls))
plot(x, y)

График нужен не для украшения, а для проверки структуры данных.
