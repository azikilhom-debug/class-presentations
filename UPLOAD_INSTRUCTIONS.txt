UPLOAD INSTRUCTIONS
-------------------
1. Download and EXTRACT this ZIP on your computer. GitHub will NOT
   automatically unzip an uploaded ZIP file.
2. Open the repository: https://github.com/azikilhom-debug/class-presentations
3. Stay at the ROOT of the repository (do not go into english/ or russian/).
4. Select Add file > Upload files.
5. Drag/drop the extracted index.html and the entire r/ folder
   (or use GitHub's folder upload via drag-and-drop). Make sure the paths
   remain as shown below, not all files in the root.
6. Commit the changes. GitHub may ask you to confirm replacing index.html.

UPLOAD PATHS
------------

Do NOT delete any existing files or folders.
Do NOT replace english/index.html, russian/index.html, or uzbek/index.html.

After deployment, open your existing GitHub Pages home URL and click
"R Programming (EN / RU)" to verify the new language selection page.
